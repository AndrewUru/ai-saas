# Derivación avanzada a personas

Usa esta guía para diseñar una lógica de escalado que resulte fluida para tus clientes.

## Señales a vigilar

- "Quiero hablar con una persona" o "llámame"
- Preguntas sobre precios o compras corporativas
- Peticiones repetidas tras respuestas fallidas

## Flujo recomendado

1. Añade un mensaje de **soporte humano** que deje claras las expectativas.
2. Usa una URL de fallback para abrir una página de reservas.
3. Etiqueta las conversaciones que requieren seguimiento.

## Ejemplo de mensaje de escalado

```text
Puedo ponerte en contacto con nuestro equipo. Compárteme tu email y el mejor momento para contactarte.
```
